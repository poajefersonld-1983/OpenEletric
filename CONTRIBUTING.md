# Como contribuir

Veja o [guia de desenvolvimento](docs/desenvolvimento.md). Para um problema, descreva a versão, os passos e o resultado esperado. Exemplos sintéticos pequenos ajudam a reproduzir sem expor dados de clientes.

Mudanças de cálculo precisam indicar unidades, hipóteses, limites e uma conferência independente. Não inclua tokens, dados pessoais ou arquivos proprietários de terceiros. O código próprio deste projeto é distribuído sob MIT.
